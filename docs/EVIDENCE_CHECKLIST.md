| Evidence | How to capture | Status |
|---|---|---|
| Repository | `git status` / repository screenshot | TODO |
| Branch | `git branch --show-current` | TODO |
| File changes | `git status --short` | TODO |
| Backend build | `mvn test` or `mvn package` | TODO |
| Backend startup | `mvn spring-boot:run` terminal output | TODO |
| Health API | `GET /api/health` | TODO |
| POS status API | `GET /api/pos/status` | TODO |
| Serial/IMEI status API | `GET /api/serial-imei/status` | TODO |
| Frontend build | `npm run build` | TODO |
| Frontend UI | browser screenshot | TODO |
| FE/BE integration | click status check and capture response | TODO |
| Commit hash | `git log -1 --oneline` after your real commit | TODO |
| Review/PR | PR URL / reviewer evidence if applicable | TODO |

**Rule:** Never change `TODO` to `PASS` without real execution evidence.
