# TV4 Week 2 — Code Review Checklist

Before handing the Week 2 deliverable to PM/Architect:

- [ ] Repository opens without missing source files.
- [ ] `git status` is understood; no generated folders are accidentally committed.
- [ ] Frontend dependencies install successfully.
- [ ] `npm run build` succeeds.
- [ ] Spring Boot dependencies resolve successfully.
- [ ] `mvn test` succeeds.
- [ ] Backend starts on port 8080.
- [ ] `/api/health` responds successfully.
- [ ] `/api/pos/status` responds successfully.
- [ ] `/api/serial-imei/status` responds successfully.
- [ ] Frontend starts on port 5173.
- [ ] Frontend can call POS and Serial/IMEI status endpoints.
- [ ] No payment/inventory/customer/business rules were invented in the skeleton.
- [ ] README matches the real repository.
- [ ] Real commit hash is recorded after the student commits.
- [ ] Reviewer/PR evidence is attached if the team requires it.
